# Rick and Morty — каталог персонажей

Тестовое задание: небольшое Flutter-приложение для просмотра и поиска персонажей вселенной Rick and Morty. Данные берутся из публичного [Rick and Morty API](https://rickandmortyapi.com/documentation).

<video src="mobile/app/docs/1.mov" controls width="100%"></video>

## Что сделано

- Каталог: портрет, имя и статус, постраничная подгрузка при прокрутке, поиск по имени.
- Состояния загрузки, ошибки и пустой выдачи.
- Карточка персонажа: имя, изображение, статус, вид, происхождение и текущая локация. Возврат к списку сохраняет его состояние.
- Модули по Clean Architecture: публичный API фичи — сущности и use case, репозитории остаются внутри модуля.
- HTTP через Dio и Retrofit, повтор запросов при `429`, картинки из кэша, отслеживание сети.

## Стек

Flutter и Dart. Состояние экранов — `flutter_bloc`, навигация — `go_router`, сборка зависимостей — `get_it` и `injectable`.

Сеть и данные: `dio`, `retrofit`, `json_serializable`. Картинки — `cached_network_image` и `flutter_cache_manager`. Сеть устройства — `connectivity_plus`. Общие примитивы (`Result`, ошибки, стримы) — пакет `core` на `rxdart` и `equatable`.

## Задание

> Каталог персонажей Rick and Morty
>
> Необходимо разработать небольшое приложение для просмотра и поиска персонажей вселенной Rick and Morty.
>
> API: https://rickandmortyapi.com/documentation

**Функциональные требования**

1. Каталог персонажей
   - Отображение списка персонажей с изображением, именем и статусом.
   - Постраничная загрузка при прокрутке списка.
   - Поиск персонажей по имени.
   - Обработка состояний загрузки, ошибки и отсутствия результатов.
2. Детальная информация
   - Экран с подробной информацией о персонаже.
   - Отображение имени, изображения, статуса, вида, происхождения и текущей локации.
   - Корректный возврат к списку с сохранением его состояния.

**Технические требования**

- Flutter / Dart.
- REST API.
